# Digital Resto

Site vitrine de l'agence et démonstration d'un restaurant italien.

- Page agence : /index.html
- Démonstration restaurant : /restaurant-italien/

## Publication Netlify
Importer le dépôt GitHub `dhoomsingh/digital-resto` dans Netlify, laisser le répertoire de publication vide (racine) et lancer le déploiement.

## À personnaliser avant commercialisation
- Remplacer l'adresse e-mail provisoire par une adresse réellement contrôlée.
- Ajouter les mentions légales, politique de confidentialité et informations de l'entreprise.
- La page La Tavola est fictive : remplacer les coordonnées, horaires, menu et visuels avant toute utilisation réelle.
- Les tarifs sont indicatifs et doivent être confirmés sur devis.

Le bouton de contact utilise un lien e-mail (mailto), pas un formulaire avec stockage ou envoi serveur.
